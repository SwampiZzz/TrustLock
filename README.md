# Hackathon Practice Repository

> **Tech Stack:** JavaScript · CashScript · React

This repository contains our team's practice work in preparation for the upcoming CashScript Hackathon. Its purpose is to simulate the development process, improve collaboration, and rehearse building blockchain applications under time constraints.

> **Note:** This repository is for practice and learning only. It is **not** intended to be reused as a competition submission.

---

# Objectives

Our practice focuses on developing the following skills:

* Designing secure CashScript smart contracts
* Writing and maintaining automated contract tests
* Integrating contracts with JavaScript applications
* Building React frontends for blockchain interactions
* Working with a local Regtest environment
* Practicing rapid MVP development
* Improving team communication and decision-making under time pressure

# Development Workflow

1. Analyze the problem statement.
2. Define the minimum viable product (MVP).
3. Design the CashScript contract interface.
4. Implement and test the contract.
5. Integrate with JavaScript.
6. Connect the frontend.
7. Verify the complete transaction flow.
8. Prepare a short demonstration.

# Project Principles

* Build the smallest working MVP first.
* Prioritize correctness over features.
* Test every contract change.
* Keep commits small and descriptive.
* Communicate architecture decisions before implementation.
* Avoid premature optimization.
* Document important decisions as the project evolves.
